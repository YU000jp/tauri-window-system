## Default Permission

Allow the window-system plugin commands

#### This default permission set includes the following:

- `allow-open-window`
- `allow-close-window`
- `allow-list-windows`
- `allow-emit-to-window`
- `allow-restore-windows`
- `allow-send-window-message`
- `allow-broadcast-window-message`
